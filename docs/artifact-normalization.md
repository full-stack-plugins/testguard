# Local artifact references and domain normalization

The `testguard.local/v1` execution record owns domain `ArtifactRef` values: `uri`, bare lowercase SHA-256 `digest`, `media_type`, and byte `size`. This is not GuardEngine's integration ref (`mediaType`, algorithm-prefixed digest, no domain size field). Strict deserialization rejects mixing the two. Existing transport explicitly serializes domain records into separate artifacts; no implicit ref conversion or trust grant occurs.

`ArtifactRef::parse` accepts at most4096 bytes before deserialization, rejects unknown/duplicate fields, and validates the expected attempt. Attempt/name are nonempty ASCII alphanumeric, dot, dash or underscore components of at most256 bytes; `.` and `..` are forbidden. URI is exactly `evidence://attempt/name`. Media metadata is nonblank printable ASCII of at most256 bytes. Artifact size is bounded to16MiB before hashing. The collector/store keep their stricter4MiB limits; this profile does not increase them. `validate` checks metadata and attempt scope; `verify` checks exact byte length and digest only, and must not be treated as context/authentication verification. Neither function resolves paths, networks or compressed data.

`canonical_digest` preserves the existing sorted-key serde_json representation. Object key ordering and JSON whitespace do not affect the typed value digest; array order remains significant. It does not claim RFC8785, cross-language floating-point normalization, semantic set sorting, or bounded arbitrary generic serialization. Callers validate and preflight domain input before normalization. SHA-256 of original report bytes remains distinct: reformatting raw JSON/XML changes the artifact digest and does not rewrite the original report. Wall-clock time is not consulted.

Tests normalize validated obligation, frozen plan, attempt, coverage and finding fixtures ten times each; those are local domain fixtures, not execution/authority qualification. Closed JSON Schema records structural limits; runtime additionally enforces expected attempt, safe components and nonblank media metadata. Unknown metadata, conflicting digest/size, foreign attempts and oversized inputs reject.
